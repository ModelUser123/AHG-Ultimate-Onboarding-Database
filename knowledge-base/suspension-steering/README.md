## Suspension Overview

### Suspension Types

**Independent Front Suspension (IFS)**:
- MacPherson strut
- Double wishbone (A-arm)
- Short/Long arm (SLA)

**Independent Rear Suspension (IRS)**:
- Multi-link
- MacPherson strut
- Semi-trailing arm

**Solid Axle (Live Axle)**:
- Leaf spring
- Coil spring with links
- Common on trucks and older vehicles

### Suspension Components

**Springs**:
- Coil springs
- Leaf springs
- Torsion bars
- Air springs

**Shock Absorbers/Struts**:
- Dampen spring oscillation
- Strut = shock + spring mount + steering knuckle attachment

**Control Arms**:
- Upper and/or lower
- Connect wheel to frame
- Allow up/down movement

**Ball Joints**:
- Allow pivoting movement
- Load-carrying vs. follower (friction)

**Bushings**:
- Rubber/polyurethane
- Isolate vibration
- Allow controlled movement

**Sway Bar (Stabilizer Bar)**:
- Reduces body roll
- Connected via end links

**Strut/Shock Mounts**:
- Upper bearing allows steering rotation (struts)
- Isolates suspension noise

## Steering Systems

### Steering Types

**Rack and Pinion**:
- Most common today
- Pinion gear meshes with rack
- Tie rods connect rack to knuckles

**Recirculating Ball**:
- Found on trucks, older vehicles
- Steering box with sector shaft
- Pitman arm connects to steering linkage

### Power Steering Types

**Hydraulic Power Steering (HPS)**:
- Engine-driven pump
- Hydraulic fluid pressure
- Hoses and lines

**Electric Power Steering (EPS)**:
- Electric motor assist
- On steering column or rack
- No fluid, more efficient

**Electro-Hydraulic (EHPS)**:
- Electric motor drives pump
- Still uses hydraulic fluid

### Steering Components

**Tie Rods**:
- Inner and outer
- Connect rack to steering knuckle
- Allow steering angle adjustment

**Steering Gear/Rack**:
- Converts steering wheel rotation to lateral movement

**Steering Column**:
- Contains steering shaft, ignition, switches
- May have intermediate shaft with U-joints

**Power Steering Pump** (hydraulic):
- Engine-driven
- Provides hydraulic pressure

## Inspection Procedures

### Visual Inspection

**Suspension**:
- [ ] Check for fluid leaks on shocks/struts
- [ ] Inspect springs for cracks, sag
- [ ] Look for damaged/torn boots
- [ ] Check for worn/cracked bushings
- [ ] Inspect sway bar links

**Steering**:
- [ ] Check power steering fluid level/condition
- [ ] Inspect hoses for leaks, cracks
- [ ] Look for torn tie rod boots
- [ ] Check steering gear for leaks
- [ ] Inspect steering shaft boots

### Loaded Suspension Test (On Ground)

**Ball Joints**:
1. Position pry bar under tire
2. Lift up and down
3. Observe ball joint for play
4. Maximum play: typically 0.050" (check spec)

**Tie Rod Ends**:
1. Grasp tire at 3 and 9 o'clock
2. Push/pull to check for play
3. Observe tie rod ends
4. Any play = replacement needed

**Wheel Bearings**:
1. Grasp tire at 12 and 6 o'clock
2. Rock tire in/out
3. Any play = bearing check needed

### Unloaded Suspension Test (Wheel Off Ground)

**Ball Joints**:
1. Lift vehicle
2. Use pry bar between control arm and knuckle
3. Check for vertical play

**Tie Rod Ends**:
1. Grasp tie rod and twist/push/pull
2. Any looseness = replacement

### Bounce Test (Shocks/Struts)

**Procedure**:
1. Push down on corner of vehicle
2. Release
3. Vehicle should return to rest in 1-2 bounces
4. Excessive bouncing = worn shock/strut

### Steering Play Check

**At Wheels**:
1. Center steering wheel
2. Turn wheel left-right
3. Maximum play: typically 2" or less at wheel rim

**At Tie Rods**:
1. Have assistant turn wheel slightly left-right
2. Observe all steering components
3. Any looseness indicates worn component

## Component Service

### Shock/Strut Replacement

**Symptoms Requiring Replacement**:
- Oil leaking from shock body
- Excessive body roll or nose dive
- Cupped tire wear
- Bouncy ride
- Clunking over bumps

**Strut Replacement Procedure**:
1. Loosen top mount nuts (wheel on ground)
2. Lift and support vehicle
3. Remove wheel
4. Disconnect sway bar link
5. Disconnect brake line bracket
6. Mark strut-to-knuckle position
7. Remove strut-to-knuckle bolts
8. Remove upper strut mount nuts
9. Remove strut assembly
10. Use spring compressor to disassemble
11. Transfer parts to new strut or install quick strut
12. Reassemble and install
13. Alignment required after

**CAUTION**: Spring is under extreme pressure. Use proper spring compressor.

### Ball Joint Replacement

**Types**:
- Press-in: Requires press to remove/install
- Bolt-in: Bolts to control arm
- Riveted: Remove rivets, bolt in replacement

**Procedure** (press-in):
1. Remove wheel
2. Separate ball joint from knuckle
3. Remove control arm if necessary
4. Press out old ball joint
5. Press in new ball joint
6. Reassemble
7. Alignment required

### Control Arm Replacement

**Procedure**:
1. Remove wheel
2. Disconnect sway bar link
3. Separate ball joint from knuckle
4. Mark position of alignment cam bolts (if equipped)
5. Remove control arm mounting bolts
6. Remove control arm
7. Install new control arm
8. Reassemble
9. Alignment required

**Note**: Many control arms come with bushings and ball joints pre-installed

### Tie Rod Replacement

**Outer Tie Rod**:
1. Loosen jam nut
2. Count threads exposed (for alignment approximation)
3. Separate tie rod from knuckle
4. Unscrew tie rod from inner tie rod
5. Install new tie rod, matching thread count
6. Tighten jam nut
7. Alignment required

**Inner Tie Rod**:
1. Remove outer tie rod
2. Remove rack boot clamps
3. Use inner tie rod tool to remove
4. Install new inner tie rod
5. Torque to spec
6. Install boot and clamps
7. Install outer tie rod
8. Alignment required

### Sway Bar Link Replacement

**Symptoms**:
- Clunking over bumps
- Noise when turning

**Procedure**:
1. Remove wheel (optional but easier)
2. Hold stud while removing nut
3. Remove link from strut and sway bar
4. Install new link
5. Torque nuts to spec (typically 40-60 ft-lbs)

### Power Steering Pump Replacement

**Procedure**:
1. Remove serpentine belt
2. Disconnect hoses (catch fluid)
3. Remove mounting bolts
4. Remove pump
5. Transfer pulley if needed
6. Install new pump
7. Connect hoses
8. Reinstall belt
9. Fill and bleed system

**Bleeding Power Steering**:
1. Fill reservoir
2. Turn wheels lock to lock (engine off)
3. Check/add fluid
4. Start engine
5. Turn wheels lock to lock
6. Check for foam/bubbles
7. Repeat until quiet and fluid clear

## Wheel Alignment

### Alignment Angles

**Camber**:
- Inward/outward tilt of wheel (viewed from front)
- Positive: Top out
- Negative: Top in
- Typical spec: 0° to -1°

**Caster**:
- Forward/backward tilt of steering axis (viewed from side)
- Positive: Top back
- Affects straight-line stability and return to center
- Typical spec: +2° to +7°

**Toe**:
- Comparison of front vs. rear of tires
- Toe-in: Fronts closer
- Toe-out: Fronts farther apart
- Measured in degrees or inches
- Typical spec: 0° to slight toe-in

**Thrust Angle**:
- Direction rear axle points
- Should be parallel to vehicle centerline

### When Alignment is Needed

- After any steering/suspension repair
- Uneven tire wear
- Vehicle pulls to one side
- Steering wheel off-center
- After impact with curb/pothole
- Routine (every 12,000 miles or annually)

### Alignment Procedure

1. Check tire pressure, set to spec
2. Check/correct suspension wear before alignment
3. Position vehicle on alignment rack
4. Attach targets/sensors to wheels
5. Measure current alignment angles
6. Adjust to specification:
   - Camber: Cam bolts, shims, or eccentric adjusters
   - Caster: Strut rod, shims, or eccentric adjusters
   - Toe: Tie rod adjustment
7. Print alignment before/after report
8. Road test to verify

### Alignment Angle Effects

| Misalignment | Effect |
|--------------|--------|
| Excessive positive camber | Outer tire wear |
| Excessive negative camber | Inner tire wear |
| Toe-in excessive | Outer edge wear (feathering) |
| Toe-out excessive | Inner edge wear (feathering) |
| Caster unequal | Pull to low caster side |

## Wheel Bearings

### Bearing Types

**Tapered Roller (Serviceable)**:
- Older style, common on trucks
- Can be repacked with grease
- Require adjustment

**Sealed Hub Bearings**:
- Most common on modern vehicles
- Press-in or bolt-on
- Not serviceable, replace as unit

### Bearing Inspection

**Noise Test**:
1. Drive at highway speed
2. Sway vehicle left-right
3. Noise changes = bearing on weight-transfer side

**Play Test**:
1. Lift wheel
2. Grasp at 12 and 6 o'clock
3. Rock in and out
4. Play indicates worn bearing

**Spin Test**:
1. Lift wheel
2. Spin wheel by hand
3. Listen for grinding, roughness

### Bearing Replacement

**Hub Assembly Replacement**:
1. Remove wheel
2. Remove brake caliper and rotor
3. Disconnect ABS sensor
4. Remove hub mounting bolts (may be from behind)
5. Remove hub assembly
6. Install new hub assembly
7. Torque bolts to spec
8. Reassemble brakes
9. Test drive

**Press-In Bearing Replacement**:
1. Remove knuckle from vehicle
2. Press out old bearing
3. Press in new bearing
4. Reassemble

## Troubleshooting

### Noise Diagnosis

| Noise | When | Likely Cause |
|-------|------|--------------|
| Clunk | Over bumps | Ball joint, tie rod, sway bar link |
| Squeak | Over bumps | Dry bushing, spring insulator |
| Groan | Turning | Power steering, CV joint |
| Howl | Steady speed | Wheel bearing |
| Click | Turning (accelerating) | CV joint |
| Knock | Bumps or turning | Strut mount |

### Pull Diagnosis

| Symptom | Check |
|---------|-------|
| Constant pull | Alignment, tire pressure, brake drag |
| Pull when braking | Brake issue (seized caliper) |
| Pull on acceleration | Torque steer, CV axle |
| Wanders | Loose steering components, worn parts |

### Vibration Diagnosis

| Speed | Likely Cause |
|-------|--------------|
| Low speed | Flat spot on tire, bent wheel |
| 40-50 mph | Wheel balance (front) |
| 55-70 mph | Wheel balance (rear), driveshaft |
| All speeds | Tire defect, bent wheel |
| Only braking | Brake rotor issue |

### Tire Wear Patterns

| Pattern | Cause |
|---------|-------|
| Center wear | Overinflation |
| Edge wear (both) | Underinflation |
| One side wear | Camber issue |
| Feathered edges | Toe issue |
| Cupping/scalloping | Worn shocks/struts |
| Flat spots | Imbalance or lockup |

## Quick Reference

### Common Torque Specifications

| Component | Typical Torque |
|-----------|----------------|
| Ball joint nut | 50-90 ft-lbs |
| Tie rod end nut | 35-50 ft-lbs |
| Control arm bolts | 80-120 ft-lbs |
| Strut-to-knuckle | 75-100 ft-lbs |
| Strut mount nuts | 30-40 ft-lbs |
| Hub bearing bolts | 65-85 ft-lbs |
| Sway bar link | 40-60 ft-lbs |
| Wheel lug nuts | 80-100 ft-lbs |

*Always verify with vehicle-specific specifications*

### Inspection Intervals

| Component | Inspect | Replace If |
|-----------|---------|------------|
| Shocks/struts | Every oil change | Leaking, bouncy |
| Ball joints | Every oil change | Any play |
| Tie rods | Every oil change | Any play |
| Bushings | Every oil change | Cracked, torn |
| Wheel bearings | Every brake job | Noise, play |

## Safety Notes

1. **Use proper support** - Never work under vehicle on jack alone
2. **Spring compressor** - Use only proper tools for spring work
3. **Torque specifications** - Critical for safety components
4. **Alignment after repairs** - Prevents tire wear and unsafe handling
5. **Test drive carefully** - Verify repairs before returning to customer
