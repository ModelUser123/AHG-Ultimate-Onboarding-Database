## Parts Quality Levels

### Understanding Parts Grades

**OE (Original Equipment)**:
- Genuine parts from vehicle manufacturer
- Available through dealership
- Highest price point
- Exact fit and function guaranteed
- Original warranty terms

**OES (Original Equipment Supplier)**:
- Same manufacturer as OE parts
- Sold under supplier's brand (not carmaker)
- Lower cost than OE
- Same quality as OE
- Examples: Bosch, Denso, Continental

**Premium Aftermarket**:
- Third-party manufacturers
- Meet or exceed OE specifications
- Established brand reputation
- Competitive pricing
- Good warranty coverage

**Economy/Value**:
- Budget-priced alternatives
- Variable quality
- Shorter warranty
- Suitable for older vehicles or budget repairs

**Remanufactured**:
- Used cores rebuilt to specifications
- Significant cost savings
- Good for alternators, starters, calipers
- Verify remanufacturer quality

**Used/Recycled**:
- Salvage yard parts
- Lowest cost
- No warranty typically
- Good for body parts, some mechanical

## Ordering Best Practices

### Information Needed

**Minimum Information**:
- Year
- Make
- Model
- Engine size/type

**Ideal Information**:
- VIN (most accurate)
- Current mileage
- Production date
- Option codes (if applicable)

### VIN Decoding

```
Position 1-3: World Manufacturer Identifier
Position 4-8: Vehicle attributes (engine, body, etc.)
Position 9: Check digit
Position 10: Model year
Position 11: Plant code
Position 12-17: Production sequence
```

**Year Codes** (Position 10):
| Code | Year | Code | Year |
|------|------|------|------|
| A | 2010 | K | 2019 |
| B | 2011 | L | 2020 |
| C | 2012 | M | 2021 |
| D | 2013 | N | 2022 |
| E | 2014 | P | 2023 |
| F | 2015 | R | 2024 |
| G | 2016 | S | 2025 |
| H | 2017 | | |
| J | 2018 | | |

### Common Ordering Mistakes

**Avoid These Errors**:
1. Wrong year (especially for mid-year changes)
2. Missing engine designation
3. Not specifying 2WD vs. 4WD
4. Not checking for submodels
5. Assuming parts are the same across models
6. Not verifying part before installation

### Verifying Parts

**Before Installing**:
- Compare part numbers
- Visually compare old vs. new
- Check connector types
- Verify bolt patterns
- Confirm dimensions match

## Parts Warranty

### Standard Warranties

| Part Type | Typical Warranty |
|-----------|------------------|
| Brake pads | 12 months/12,000 miles |
| Rotors | 12 months/12,000 miles |
| Starters/Alternators | 12-24 months |
| Water pumps | 12-24 months |
| Suspension parts | 12-24 months (some lifetime) |
| Batteries | 24-36 months prorated |
| Sensors | 12 months |

### Warranty Claim Process

1. **Document the Failure**:
   - Take photos
   - Note mileage and date
   - Keep original RO

2. **Contact Vendor**:
   - Get RA (Return Authorization) number
   - Confirm warranty coverage
   - Understand replacement process

3. **Return Part**:
   - Include paperwork
   - Ship within specified timeframe
   - Keep tracking info

4. **Credit/Replacement**:
   - Verify credit issued
   - Track replacement part
   - Document for future reference

### What Voids Warranty

- Improper installation
- Modifications
- Consequential damage
- Exceeding specifications
- Not following installation instructions

## Core Returns

### Understanding Core Charges

**What is a Core?**:
- Used part returned for remanufacturing
- Charged at time of purchase
- Credited when returned

**Common Core Parts**:
- Starters
- Alternators
- Brake calipers
- Power steering pumps
- Rack and pinions
- A/C compressors
- Radiators

### Core Return Requirements

**For Full Credit**:
- Return within 30 days (typically)
- Same part type as purchased
- Rebuildable condition
- No missing components
- Not cracked or broken beyond repair

**Reduced Core Credit**:
- Damaged beyond rebuildable
- Missing components
- Wrong core returned
- Late return

### Core Management Tips

1. Tag cores immediately when removed
2. Store in designated area
3. Track core credits owed
4. Return cores with regular orders
5. Verify credits appear on statements

## Parts Inventory Management

### Stock Parts to Keep

**Fast-Moving Items**:
- Oil filters (common applications)
- Air filters
- Wiper blades
- Bulbs
- Fuses
- Common belts
- Brake pads (common applications)

**Emergency Items**:
- Battery
- Serpentine belt (universal or common)
- Radiator hoses (common)
- Thermostat (common)

### Inventory Control

**Par Levels**:
- Minimum quantity to trigger reorder
- Based on usage history
- Adjusted seasonally

**Just-in-Time Ordering**:
- Order for specific jobs
- Reduces inventory investment
- Requires reliable delivery

**Inventory Turns**:
```
Annual Cost of Goods Sold ÷ Average Inventory Value = Turns
```
Goal: 6-12 turns per year

### Obsolete Inventory

**Signs of Obsolete Stock**:
- No sales in 12+ months
- Superseded by new part number
- Vehicle no longer common

**Managing Obsolete Parts**:
- Return to vendor if possible
- Sell to other shops
- Donate for tax benefit
- Scrap as last resort
