## Shop Layout

### Work Bay Organization

**Standard Bay Requirements**:
- Minimum 12' wide x 24' deep
- Adequate lighting (50+ foot-candles)
- Air supply drops
- Electrical outlets (110V and 220V)
- Oil drain access
- Tool storage area

**Optimal Bay Layout**:
```
|------ 12' ------|
|                 |
|  [Vehicle Lift] |  24'
|                 |
|  [Tool Cart]    |
|  [Work Bench]   |
|_________________|
```

### Equipment Placement

**Near Each Bay**:
- Lift controls
- Air hose reel
- Trouble light
- Creeper storage
- Parts cart area

**Central Location**:
- Alignment rack
- Tire machine
- Wheel balancer
- Brake lathe
- Parts washer
- Fluid dispensers

### Common Area Organization

**Front Office**:
- Customer waiting area
- Service counter
- Parts storage (small)
- Restrooms

**Back Shop**:
- Break room
- Restrooms
- Locker area
- Training area

**Outside**:
- Customer parking
- Overflow vehicle storage
- Dumpster/recycling
- Bulk fluid storage

## Tool Storage Systems

### Shop Tool Cabinets

**Wall-Mounted Systems**:
- Pegboard with hooks
- Slat wall systems
- Shadow boards
- Magnetic strips

**Floor Storage**:
- Rolling tool carts
- Stationary cabinets
- Drawer systems
- Bulk storage racks

### Shadow Boards

**Benefits**:
- Visual organization
- Easy identification of missing tools
- Faster tool retrieval
- Accountability

**Creating Shadow Boards**:
1. Select tools for board
2. Trace tool outlines
3. Paint outlines contrasting color
4. Mount hooks/holders
5. Label each location

### Tool Foam Organizers

**Custom Foam Inserts**:
- Cut to fit drawers
- Individual tool slots
- Quick visual inventory
- Professional appearance

**Implementation**:
1. Measure drawer dimensions
2. Select foam (Kaizen, closed-cell)
3. Lay out tools
4. Cut outlines
5. Remove foam inserts

## Shop Tool Management

### Shop-Owned Tools

**Tools Shop Should Provide**:
- Lifts and hoisting equipment
- Wheel service equipment
- Diagnostic equipment (OE scan tools)
- Specialty tools (infrequent use)
- Fluid handling equipment
- General shop equipment

### Tool Checkout System

**Components**:
- Tool inventory list
- Checkout log
- Tool storage location
- Return verification

**Checkout Procedure**:
1. Locate tool in inventory
2. Sign tool out on log
3. Note condition
4. Return when complete
5. Sign back in

### Tool Inventory

**Regular Inventory**:
- Weekly check of common tools
- Monthly full inventory
- Track losses and damage
- Budget for replacement

**Tracking Methods**:
- Paper log
- Spreadsheet
- Tool management software
- Barcode system

### Lost/Damaged Tool Policy

**Sample Policy**:
> "Tools checked out are the responsibility of the signing technician. Lost tools must be reported immediately. Damaged tools should be reported and removed from service. Repeated losses may result in disciplinary action."

## Tool Maintenance

### Daily Maintenance

**Before Use**:
- Visual inspection
- Check for damage
- Verify proper function
- Clean if needed

**After Use**:
- Wipe clean
- Return to proper location
- Report any issues

### Torque Wrench Maintenance

**Care Requirements**:
- Store at lowest setting
- Never use as breaker bar
- Don't drop or abuse
- Calibrate annually
- Keep clean and dry

**Calibration**:
- Send to certified facility
- Or check with calibration arm
- Document calibration date

### Power Tool Maintenance

**Electric Tools**:
- Check cords and plugs
- Inspect switches
- Keep vents clear
- Replace brushes as needed

**Pneumatic Tools**:
- Oil regularly (few drops daily)
- Use proper air pressure
- Use moisture separator
- Keep air lines clean

**Cordless Tools**:
- Charge batteries properly
- Don't fully deplete
- Store in moderate temperature
- Replace worn batteries

### Diagnostic Equipment

**Scan Tools**:
- Update software regularly
- Keep cables intact
- Store properly
- Clean connectors

**Meters/Scopes**:
- Check leads
- Replace batteries
- Calibrate as needed
- Store in case

## 5S Workplace Organization

### 5S Principles

**1. Sort (Seiri)**:
- Remove unnecessary items
- Red tag questionable items
- Dispose or relocate

**2. Set in Order (Seiton)**:
- Place for everything
- Everything in its place
- Labeling
- Visual controls

**3. Shine (Seiso)**:
- Clean work area
- Daily cleaning routine
- Inspection during cleaning

**4. Standardize (Seiketsu)**:
- Standard procedures
- Visual standards
- Consistent organization

**5. Sustain (Shitsuke)**:
- Maintain standards
- Regular audits
- Continuous improvement

### Implementing 5S

**Phase 1: Preparation**
- Train employees
- Define areas
- Gather supplies

**Phase 2: Sort**
- Clear all items
- Categorize: Keep, Discard, Relocate
- Remove unnecessary items

**Phase 3: Set in Order**
- Determine locations
- Create visual systems
- Label everything

**Phase 4: Shine**
- Deep clean area
- Establish cleaning schedule
- Assign responsibilities

**Phase 5: Standardize & Sustain**
- Document standards
- Create checklists
- Conduct regular audits

### 5S Audit Checklist

**Weekly Audit Items**:
- [ ] Work areas clean
- [ ] Tools in proper locations
- [ ] Walkways clear
- [ ] No unnecessary items
- [ ] Labels visible
- [ ] Safety equipment accessible
- [ ] Fluids properly stored
- [ ] Waste properly disposed

## Shop Organization Tips

### Workbench Setup

**Essentials**:
- Vise
- Good lighting
- Power strip
- Parts tray
- Trash bin
- Fire extinguisher nearby

### Mobile Work Carts

**Setup Suggestions**:
- Frequently used tools on top
- Heavy items on bottom
- Parts trays
- Trash bag holder
- Fluid catch pan

### End-of-Day Routine

1. Return all tools to proper location
2. Clean work area
3. Dispose of waste properly
4. Secure vehicle if on lift
5. Complete paperwork
6. Report any issues
