## Brake System Overview

### Components

**Hydraulic System**:
- Master cylinder
- Brake lines (steel and flexible)
- Brake fluid reservoir
- Proportioning/combination valve
- ABS modulator (if equipped)

**Disc Brakes**:
- Rotors
- Calipers
- Brake pads
- Caliper slides/pins
- Caliper brackets
- Hardware (clips, shims)

**Drum Brakes**:
- Drums
- Wheel cylinders
- Brake shoes
- Return/hold-down springs
- Adjusters
- Backing plates

**Parking Brake**:
- Cables
- Levers/actuators
- Shoes or caliper mechanism

## Brake Inspection Procedures

### Visual Inspection Checklist

**Pedal Inspection**:
- [ ] Pedal height (spec varies, typically 6-7" from floor)
- [ ] Pedal travel (should engage within first 1/3)
- [ ] Pedal firmness (should not be spongy)
- [ ] Pedal does not sink when held

**Master Cylinder**:
- [ ] Fluid level (between MIN and MAX marks)
- [ ] Fluid condition (should be clear, not dark)
- [ ] No external leaks
- [ ] Reservoir cap seals intact

**Brake Lines**:
- [ ] No kinks or damage
- [ ] No corrosion on steel lines
- [ ] Flexible hoses not cracked, swollen, or leaking
- [ ] All connections secure

**Disc Brake Inspection**:
- [ ] Pad thickness (minimum 2-3mm typically)
- [ ] Pad wear even across surface
- [ ] Rotor thickness above minimum
- [ ] Rotor runout within spec
- [ ] No deep scoring or cracks
- [ ] Caliper slides freely
- [ ] No fluid leaks at caliper

**Drum Brake Inspection**:
- [ ] Shoe thickness (minimum 1.5mm typically)
- [ ] No oil contamination
- [ ] Drums not scored or out of round
- [ ] Wheel cylinders not leaking
- [ ] Springs intact and properly positioned
- [ ] Self-adjuster operating

**Parking Brake**:
- [ ] Holds vehicle on incline
- [ ] Proper adjustment (typically 4-7 clicks)
- [ ] Cables not frayed or seized
- [ ] Releases fully

### Measurement Procedures

**Rotor Thickness**:
1. Clean rotor surface
2. Measure at 4 points minimum
3. Compare to minimum specification stamped on rotor
4. Check thickness variation (max 0.0005" typically)

**Rotor Runout**:
1. Mount dial indicator on caliper bracket
2. Rotate rotor one full revolution
3. Maximum runout typically 0.002" - 0.003"
4. If out of spec, clean hub surface and remeasure

**Pad Thickness**:
1. Measure friction material only (not backing plate)
2. Minimum specification typically 2-3mm
3. Note: Some pads have wear indicators

**Drum Diameter**:
1. Measure at multiple points inside drum
2. Compare to maximum diameter stamped on drum
3. Check for out-of-round condition

## Disc Brake Service

### Brake Pad Replacement

**Tools Required**:
- Socket set
- C-clamp or brake piston tool
- Wire brush
- Brake cleaner
- Torque wrench
- Caliper hanger

**Procedure**:

1. **Preparation**
   - Loosen lug nuts before lifting
   - Lift vehicle and secure on jack stands
   - Remove wheel

2. **Caliper Removal**
   - Remove caliper slide pin bolts
   - Hang caliper with wire - DO NOT let it hang by brake hose
   - Note pad positions for reinstallation

3. **Pad Removal**
   - Remove old pads from caliper bracket
   - Inspect for wear pattern (uneven wear indicates caliper issue)

4. **Caliper Service**
   - Clean caliper slide pins
   - Inspect slide pin boots for tears
   - Apply silicone grease to slide pins
   - Inspect piston boot for damage

5. **Bracket Service**
   - Clean pad contact areas
   - Remove rust and debris
   - Apply brake grease to contact points (NOT to rotor or pads)

6. **Rotor Service**
   - Measure thickness and runout
   - Machine or replace if out of spec
   - Clean new rotors with brake cleaner to remove preservative

7. **Piston Compression**
   - Open bleeder (optional, prevents pushing old fluid back)
   - Use C-clamp or piston tool to compress piston
   - For rear with parking brake: use special tool to rotate and compress

8. **Installation**
   - Install new hardware if provided
   - Install new pads (note inner vs. outer if different)
   - Reinstall caliper
   - Torque slide pin bolts to spec (typically 25-35 ft-lbs)

9. **Final Steps**
   - Reinstall wheel
   - Lower vehicle
   - Pump brake pedal until firm
   - Check fluid level

**Break-In Procedure**:
1. Make 30 stops from 30 mph with moderate pressure
2. Allow 30 seconds between stops for cooling
3. Avoid hard stops for first 100 miles

### Rotor Replacement

**When to Replace**:
- Below minimum thickness
- Deep scoring (cannot be machined out)
- Cracks in friction surface
- Heat spots/hard spots
- Runout cannot be corrected

**Procedure**:
1. Remove caliper and hang aside
2. Remove caliper bracket
3. Remove rotor (may require set screws)
4. Clean hub surface thoroughly
5. Install new rotor
6. Measure runout before proceeding
7. Reinstall bracket and caliper

**Torque Specifications** (typical):
- Caliper bracket: 70-85 ft-lbs
- Caliper slide pins: 25-35 ft-lbs
- Wheel lug nuts: 80-100 ft-lbs (verify for vehicle)

---

### Caliper Rebuild/Replacement

**Symptoms of Caliper Failure**:
- Brake pull (dragging or not releasing)
- Uneven pad wear
- Fluid leak at piston
- Vehicle pulls when braking

**Rebuild vs. Replace**:
- Rebuild: Less expensive, requires more time
- Replace: More reliable, includes new hardware
- Recommendation: Replace with remanufactured unit

**Caliper Replacement**:
1. Remove caliper from bracket
2. Disconnect brake hose (use flare nut wrench)
3. Cap hose to prevent fluid loss
4. Transfer any reusable hardware to new caliper
5. Install new caliper
6. Torque hose fitting (typically 12-15 ft-lbs)
7. Bleed brake system

## Drum Brake Service

### Brake Shoe Replacement

**Tools Required**:
- Drum brake spring tools
- Hold-down spring tool
- Brake adjusting tool
- Brake cleaner

**Procedure**:

1. **Drum Removal**
   - Back off adjuster (through hole in backing plate)
   - Remove drum - may need to release parking brake
   - If stuck, apply penetrant and use drum puller

2. **Inspection Before Disassembly**
   - Take photo for reference
   - Note spring and hardware positions
   - Check wheel cylinder for leaks

3. **Disassembly**
   - Remove return springs (upper first)
   - Remove hold-down springs
   - Remove adjuster assembly
   - Remove shoes

4. **Wheel Cylinder Service**
   - If leaking: replace
   - If not leaking: inspect boots, rebuild or replace if questionable

5. **Cleaning**
   - Clean backing plate
   - Clean adjuster mechanism
   - Lubricate raised pads on backing plate

6. **Installation**
   - Install primary (short lining) and secondary (long lining) shoes
   - Install adjuster (star wheel toward rear)
   - Install hold-down springs
   - Install return springs (lower first, then upper)

7. **Adjustment**
   - Install drum
   - Expand adjuster until drum drags
   - Back off adjuster 8-10 clicks
   - Drum should spin with light drag

8. **Parking Brake**
   - Adjust parking brake cable if needed
   - Verify proper operation

---

### Wheel Cylinder Replacement

**Symptoms of Wheel Cylinder Failure**:
- Fluid leak at backing plate
- Wet appearance on shoes
- Brake pull
- Spongy pedal

**Procedure**:
1. Remove drum and shoes
2. Disconnect brake line at wheel cylinder
3. Remove wheel cylinder mounting bolts
4. Install new wheel cylinder
5. Connect brake line
6. Bleed brake at this wheel first
7. Reinstall shoes and drum

## Brake Fluid Service

### Fluid Specifications

**DOT Ratings**:
| Type | Dry Boiling Point | Wet Boiling Point | Application |
|------|-------------------|-------------------|-------------|
| DOT 3 | 401°F | 284°F | Standard vehicles |
| DOT 4 | 446°F | 311°F | Performance/European |
| DOT 5 | 500°F | 356°F | Silicone (not for ABS) |
| DOT 5.1 | 500°F | 356°F | High-performance glycol |

**Important**: 
- Never mix DOT 5 (silicone) with DOT 3/4/5.1 (glycol-based)
- Always use manufacturer-specified fluid
- DOT fluid is hygroscopic (absorbs water) - keep container sealed

### Brake Fluid Flush

**When to Flush**:
- Every 2-3 years (mileage-based schedules vary)
- When fluid appears dark or contaminated
- After any brake component replacement
- After brake failure

**Flush Procedure**:
1. Remove as much old fluid from reservoir as possible
2. Fill reservoir with fresh fluid
3. Bleed in order: RF, LF, RR, LR (furthest to closest, typically)
4. Continue until clean fluid appears at all wheels
5. Verify pedal feel
6. Check fluid level

### Brake Bleeding

**Methods**:
1. **Gravity Bleeding**: Open bleeder, let fluid flow by gravity
2. **Manual Bleeding**: Assistant pumps pedal while tech opens/closes bleeder
3. **Vacuum Bleeding**: Use vacuum pump to draw fluid through
4. **Pressure Bleeding**: Use pressure tank to push fluid through

**Manual Bleeding Procedure**:
1. Fill reservoir
2. Have assistant pump brake pedal 3-4 times, hold pressure
3. Open bleeder until pedal goes to floor
4. Close bleeder before assistant releases pedal
5. Repeat until no air bubbles
6. Move to next wheel
7. Top off reservoir frequently

**ABS Bleeding**:
- Some vehicles require scan tool to cycle ABS pump
- Follow manufacturer procedure
- May need to bleed multiple times

## ABS Systems

### ABS Components

- Wheel speed sensors (4)
- ABS module (hydraulic unit and controller)
- Pump motor
- Solenoid valves
- Warning light

### ABS Operation

Normal braking: ABS is passive
During wheel lockup:
1. Wheel speed sensor detects rapid deceleration
2. ABS module activates
3. Solenoid valves reduce pressure to that wheel
4. Pump cycles to modulate pressure
5. Process repeats 10-15 times per second

### ABS Troubleshooting

**ABS Light On**:
1. Scan for codes
2. Check wheel speed sensor air gaps
3. Check sensor wiring
4. Check tone ring for damage/debris
5. Check fluid level
6. Check system voltage

**Common ABS Codes**:
| Code | Description | Common Cause |
|------|-------------|--------------|
| C0035 | LF Wheel Speed | Sensor, wiring, tone ring |
| C0040 | RF Wheel Speed | Sensor, wiring, tone ring |
| C0045 | LR Wheel Speed | Sensor, wiring, tone ring |
| C0050 | RR Wheel Speed | Sensor, wiring, tone ring |
| C0265 | Relay Circuit | ABS relay |
| C1095 | Pump Motor | ABS pump |

### Wheel Speed Sensor Service

**Testing**:
1. Check resistance (typically 800-2000 ohms)
2. Check AC voltage output while spinning wheel
3. Check air gap (typically 0.020" - 0.050")
4. Inspect tone ring for damage

**Replacement**:
1. Disconnect electrical connector
2. Remove mounting bolt
3. Pull sensor from hub/knuckle
4. Clean mounting surface
5. Install new sensor
6. Clear codes and test drive

## Brake Specifications

### Minimum Pad Thickness

| Application | Minimum |
|-------------|---------|
| Standard pads | 2mm (3/32") |
| With wear indicator | When indicator contacts rotor |
| Performance pads | Follow manufacturer spec |

### Typical Rotor Specifications

| Measurement | Typical Spec |
|-------------|--------------|
| Minimum thickness | Stamped on rotor |
| Thickness variation | 0.0005" max |
| Lateral runout | 0.002" - 0.003" max |
| Surface finish | 50-80 Ra (micro-inches) |

### Brake Fluid DOT Specifications

Always use manufacturer-specified fluid. When in doubt:
- Domestic vehicles: DOT 3
- European vehicles: DOT 4
- Performance vehicles: DOT 4 or 5.1

## Troubleshooting

### Symptom: Soft/Spongy Pedal

**Causes**:
1. Air in system → Bleed brakes
2. Master cylinder failure → Replace
3. Brake hose internal failure → Replace hose
4. Worn pads → Replace pads
5. ABS modulator issue → Scan for codes

### Symptom: Brake Pull

**Causes**:
1. Caliper sticking → Service or replace
2. Contaminated pads → Replace pads
3. Uneven pad wear → Service caliper slides
4. Brake hose restricted → Replace hose
5. Alignment issue → Check alignment

### Symptom: Brake Noise (Squeal)

**Causes**:
1. Wear indicator → Replace pads
2. Glazed pads/rotors → Replace or resurface
3. Missing shims → Install shims
4. Incorrect pads → Use OE-spec pads
5. Caliper issue → Service caliper

### Symptom: Brake Noise (Grinding)

**Causes**:
1. Metal on metal → Replace pads and rotors
2. Debris → Remove debris
3. Rust after sitting → Normal, will clear with use

### Symptom: Pedal Pulsation

**Causes**:
1. Rotor runout → Machine or replace rotor
2. Rotor thickness variation → Replace rotor
3. Wheel bearing → Check and replace
4. Hub face debris → Clean hub surface

### Symptom: Parking Brake Doesn't Hold

**Causes**:
1. Cable out of adjustment → Adjust
2. Worn shoes → Replace
3. Seized cable → Replace cable
4. Lever mechanism worn → Repair or replace

## Brake Safety Reminders

### Critical Safety Points

1. **Never work under a vehicle supported only by a jack**
2. **Brake dust may contain asbestos - use appropriate PPE**
3. **Use proper brake cleaner only - never use carburetor cleaner**
4. **Always torque fasteners to specification**
5. **Test brakes at low speed before returning to customer**
6. **Document brake measurements on inspection form**

### Brake Failure Warning Signs

Advise customers to seek immediate service if they experience:
- Brake warning light illuminated
- Grinding noise while braking
- Pedal goes to floor
- Vehicle pulls severely when braking
- Brake fluid leak
