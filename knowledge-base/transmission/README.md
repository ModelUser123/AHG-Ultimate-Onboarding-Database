## Transmission Types

### Automatic Transmission

**Components**:
- Torque converter
- Planetary gear sets
- Clutch packs and bands
- Valve body
- Transmission Control Module (TCM)
- Input/output speed sensors
- Solenoids

**Common Types**:
- Traditional hydraulic automatic
- Electronically controlled (most modern)
- CVT (Continuously Variable)
- DCT (Dual Clutch)
- Automated manual

### Manual Transmission

**Components**:
- Clutch assembly (disc, pressure plate, release bearing)
- Input and output shafts
- Synchronizers
- Gear sets
- Shift forks and rails
- Shift cables or linkage

## Automatic Transmission Service

### Fluid Check

**Checking Procedure** (varies by vehicle):
1. Most vehicles: Engine running, warmed up, in Park
2. Some vehicles: Engine off
3. Check manufacturer procedure

**Fluid Condition**:
| Color/Condition | Status |
|-----------------|--------|
| Red/pink, clear | Good |
| Dark red, slight odor | Due for service |
| Brown/black, burnt smell | Overheated/damaged |
| Milky/foamy | Coolant contamination |
| Metallic particles | Internal wear |

### Fluid and Filter Service

**Service Interval**: Typically 30,000-60,000 miles (severe service more frequent)

**Pan Drop Service**:
1. Lift vehicle
2. Position drain pan
3. Remove pan bolts (leave one corner attached)
4. Allow fluid to drain
5. Remove pan completely
6. Remove old filter
7. Clean pan and magnet
8. Install new filter
9. Clean pan mating surface
10. Install pan with new gasket
11. Torque bolts in pattern (typically 8-12 ft-lbs)
12. Fill with specified fluid
13. Check level per manufacturer procedure

**Fluid Capacity** (typical):
- Pan drop service: 4-6 quarts
- Complete (with torque converter): 10-14 quarts

### Transmission Flush

**When Appropriate**:
- Clean fluid, preventive maintenance
- Not recommended for dirty/burnt fluid (may dislodge debris)

**Procedure** (machine):
1. Connect flush machine to cooler lines
2. Machine exchanges old fluid with new
3. Typically requires 12-16 quarts

**Controversy**: Some manufacturers recommend against flushes. Check TSBs.

### Fluid Specifications

**Common ATF Types**:
| Type | Application |
|------|-------------|
| DEXRON III/VI | GM vehicles |
| MERCON V/LV | Ford vehicles |
| ATF+4 | Chrysler/Dodge/Jeep |
| Type T-IV | Toyota |
| DW-1 | Honda |
| SP-III/IV | Hyundai/Kia |
| Multi-vehicle ATF | May be compatible (verify) |

**CRITICAL**: Always use manufacturer-specified fluid. Wrong fluid can cause shift problems or damage.

## Manual Transmission Service

### Clutch System

**Components**:
- Clutch disc
- Pressure plate
- Release (throw-out) bearing
- Pilot bearing/bushing
- Flywheel
- Release fork
- Hydraulic system (master/slave cylinder) or cable

**Clutch Inspection**:
| Symptom | Likely Cause |
|---------|--------------|
| Slipping (RPM rise without speed increase) | Worn disc, oil contamination |
| Chattering | Contaminated disc, worn flywheel |
| Hard pedal | Worn pressure plate, cable/hydraulic issue |
| Noise (pedal up) | Input shaft bearing |
| Noise (pedal down) | Release bearing |
| Can't shift into gear | Clutch not releasing |

### Clutch Replacement

**Procedure Overview**:
1. Remove transmission
2. Mark flywheel/pressure plate position (for balance)
3. Loosen pressure plate bolts evenly
4. Remove pressure plate and disc
5. Inspect flywheel - resurface or replace if needed
6. Replace pilot bearing
7. Install new disc (clutch alignment tool required)
8. Install pressure plate, torque evenly
9. Install new release bearing
10. Reinstall transmission
11. Adjust clutch if cable type
12. Bleed hydraulic system if equipped

**Flywheel Inspection**:
- Check for hot spots (blue discoloration)
- Check for scoring
- Measure for warpage (max typically 0.005")
- Dual-mass flywheel: Check for excessive play

### Manual Transmission Fluid

**Types**:
| Vehicle | Common Fluid |
|---------|--------------|
| GM | Synchromesh, Dexron |
| Ford | MERCON/ATF, gear oil |
| Chrysler | ATF+4, gear oil |
| Honda | MTF (manufacturer specific) |
| Toyota | Gear oil, ATF |
| European | Gear oil 75W-90 |

**Service Interval**: Typically 30,000-60,000 miles

**Level Check**:
1. Vehicle level
2. Remove fill plug (usually on side)
3. Fluid should be at bottom of fill hole
4. Add as needed

## Transmission Diagnostics

### Automatic Transmission Scan Data

**Key Parameters**:
| Parameter | Normal |
|-----------|--------|
| Input shaft speed | Should match engine RPM in gear |
| Output shaft speed | Should match vehicle speed |
| Gear ratio | Should match expected for gear |
| Fluid temperature | Under 200°F normal driving |
| Line pressure | Varies by gear and load |
| TCC slip | Minimal when locked |

### Shift Quality Issues

**Harsh/Hard Shifts**:
- Low fluid level
- Incorrect fluid
- Faulty pressure control solenoid
- Valve body issue
- Mechanical wear

**Soft/Flare Shifts**:
- Low fluid
- Worn clutch packs
- Leaking seals
- Valve body issue

**Delayed Engagement**:
- Low fluid
- Worn clutch packs
- Pump wear
- Valve body issue

**Slipping**:
- Low fluid
- Worn clutch packs
- Incorrect fluid
- Solenoid issue

### Transmission Codes

**Common Codes**:
| Code | Description | Likely Cause |
|------|-------------|--------------|
| P0700 | Trans Control System | TCM detected fault |
| P0705 | Trans Range Sensor | PRNDL switch |
| P0715 | Input Speed Sensor | Sensor, wiring |
| P0720 | Output Speed Sensor | Sensor, wiring |
| P0730 | Incorrect Gear Ratio | Clutch slip, mechanical |
| P0740 | TCC Circuit | TCC solenoid, wiring |
| P0741 | TCC Performance | TCC stuck, solenoid |
| P0750 | Shift Solenoid A | Solenoid, valve body |
| P0755 | Shift Solenoid B | Solenoid, valve body |

### Road Test Procedure

**Preparation**:
1. Check fluid level and condition
2. Scan for codes
3. Note customer complaint

**Test Procedure**:
1. Start with cold transmission
2. Note engagement quality (into D, R)
3. Light throttle - check all gear shifts
4. Moderate throttle - check shift points
5. Full throttle - check WOT shift points
6. Check TCC engagement at steady cruise
7. Check downshift quality
8. Note any abnormal noises or behavior

## CVT Transmission

### CVT Operation

**Components**:
- Primary pulley (drive)
- Secondary pulley (driven)
- Steel belt or chain
- Valve body
- CVT Control Module

**How It Works**:
- Pulleys change diameter to vary ratio
- No fixed gear ratios
- Smooth, stepless acceleration

### CVT Service

**Fluid**:
- **CRITICAL**: Use ONLY CVT-specific fluid
- Do NOT use regular ATF
- Check manufacturer specification

**Service Interval**: Typically 30,000-60,000 miles

**Common Issues**:
| Issue | Possible Cause |
|-------|---------------|
| Jerking/shuddering | Fluid degradation, belt wear |
| Slipping | Belt wear, pulley wear, fluid |
| Whining noise | Bearing wear, low fluid |
| No movement | Belt failure, pulley damage |

## Driveline Components

### Driveshaft Service

**Inspection**:
- Check U-joints for play/binding
- Inspect CV boots (FWD/AWD)
- Look for dents or damage
- Check balance weights

**U-Joint Replacement**:
1. Mark driveshaft position
2. Remove driveshaft
3. Remove U-joint clips
4. Press out old U-joint
5. Install new U-joint
6. Install clips
7. Reinstall driveshaft

### CV Axle Service

**Symptoms of CV Failure**:
| Symptom | Likely Cause |
|---------|--------------|
| Clicking when turning | Outer CV joint |
| Clunking during acceleration | Inner CV joint |
| Vibration at highway speed | CV joint or axle damage |
| Grease spray inside fender | Torn CV boot |

**Replacement**:
1. Remove wheel
2. Remove axle nut
3. Disconnect lower ball joint
4. Pull hub assembly outward
5. Remove axle from transmission
6. Install new axle (new seal if needed)
7. Reassemble
8. Torque axle nut (typically 150-200 ft-lbs)

### Differential Service

**Fluid Check**:
1. Remove fill plug
2. Fluid should be at fill hole level
3. Check condition and smell

**Fluid Types**:
| Application | Fluid |
|-------------|-------|
| Open differential | 75W-90 gear oil |
| Limited slip | 75W-90 + friction modifier |
| Synthetic | 75W-140 synthetic |

**Service Interval**: Typically 30,000-60,000 miles

## Common Repairs

### Shift Solenoid Replacement

**Symptoms**:
- Stuck in gear
- Wrong gear engagement
- Harsh shifts
- Transmission codes

**Procedure** (external solenoids):
1. Identify faulty solenoid from codes
2. Remove transmission pan
3. Disconnect electrical connectors
4. Remove solenoid(s)
5. Install new solenoid(s)
6. Reinstall pan
7. Fill fluid, clear codes, test

### Transmission Mount Replacement

**Symptoms**:
- Vibration
- Clunking when shifting
- Excessive movement

**Procedure**:
1. Support transmission
2. Remove mount bolts
3. Raise transmission slightly
4. Remove mount
5. Install new mount
6. Lower transmission onto mount
7. Torque bolts to spec

### Speed Sensor Replacement

**Location**:
- Input speed sensor: Usually near pump
- Output speed sensor: Usually near output shaft/tailshaft
- Vehicle speed sensor: On transmission or transfer case

**Procedure**:
1. Locate sensor
2. Disconnect electrical connector
3. Remove mounting bolt (if equipped)
4. Pull sensor straight out
5. Install new sensor with new O-ring
6. Clear codes, test drive

## Transmission Repair Decision Guide

### When to Service vs. Rebuild

**Service When**:
- Preventive maintenance
- Minor shift issues with clean fluid
- After adding correct fluid type

**Rebuild When**:
- Major shift problems
- Internal codes
- Burnt fluid with debris
- Slipping in multiple gears

### Transmission Options

| Option | Pros | Cons |
|--------|------|------|
| Rebuild | Custom specs, warranty | Labor intensive, downtime |
| Remanufactured | Quick turnaround, warranty | Core charge, cost |
| Used | Lower cost | Unknown condition |
| New | Factory warranty | Highest cost |

## Safety Notes

### Transmission Service Safety

1. Use proper support when under vehicle
2. ATF is flammable - keep away from heat sources
3. Transmission components may be hot
4. Wear gloves - ATF contains additives
5. Properly dispose of old fluid
6. Never work under vehicle supported by jack alone
