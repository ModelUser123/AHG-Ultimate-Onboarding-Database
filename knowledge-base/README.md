## Quick Reference Cards

### Emergency Procedures
- **Fire**: PASS method (Pull, Aim, Squeeze, Sweep)
- **Chemical Spill**: Contain, Ventilate, Clean, Report
- **Injury**: First aid kit location, emergency contacts posted

### Common Diagnostic Starting Points
| Symptom | First Check | Second Check |
|---------|-------------|--------------|
| No Start | Battery voltage | Fuel pressure |
| Overheating | Coolant level | Thermostat |
| Brake Noise | Pad thickness | Rotor condition |
| Check Engine | Scan for codes | Freeze frame data |

### Key Safety Reminders
- Always disconnect battery before electrical work
- Use jack stands - never trust hydraulic jack alone
- Wear safety glasses and appropriate PPE
- Keep fire extinguisher accessible
