## General Torque Guidelines

### Why Proper Torque Matters

- **Under-torqued**: Fastener can loosen, cause leaks, allow movement
- **Over-torqued**: Stretch/break fastener, strip threads, distort gasket

### Torque Factors

**Factors Affecting Torque**:
- Thread condition (clean, dry, lubricated)
- Thread size and pitch
- Fastener grade/strength
- Surface condition
- Gasket type
- Material being fastened

### Lubrication Effects

| Thread Condition | Torque Adjustment |
|------------------|-------------------|
| Dry (as spec'd) | 100% specified torque |
| Lightly oiled | Reduce by 15-20% |
| Anti-seize | Reduce by 20-25% |
| Moly paste | Reduce by 30-40% |

**Note**: Some specifications assume lubricated threads. Always verify.

## Engine Fasteners

### Cylinder Head Bolts

**General Procedure**:
Most modern engines use TTY (Torque-to-Yield) bolts that cannot be reused.

**Typical Multi-Step Sequence** (example):
1. Hand start all bolts
2. Torque all to 30 ft-lbs in sequence
3. Torque all to 60 ft-lbs in sequence
4. Turn all bolts +90° in sequence
5. (Some require additional +90° step)

**Common Head Bolt Torque Ranges**:
| Application | Torque Range |
|-------------|--------------|
| Small 4-cylinder | 60-75 ft-lbs |
| V6/V8 | 65-95 ft-lbs |
| Aluminum head | Lower range |
| Iron head | Higher range |
| TTY bolts | Follow angle spec |

## Torque Procedures

### Proper Torquing Steps

1. **Clean threads** - Remove dirt, debris, old sealant
2. **Inspect threads** - Check for damage, cross-threading
3. **Lubricate if specified** - Apply oil, anti-seize as required
4. **Hand-start fasteners** - Ensure proper thread engagement
5. **Snug fasteners** - Bring to light contact
6. **Apply torque in pattern** - Usually center-out or criss-cross
7. **Final torque** - May be multiple passes

### Torque Sequences

**Round/Square Pattern** (cylinder heads, intake):
```
        8   4   1   5   9
        7   3   2   6   10
```
Start at center, work outward alternating sides.

**4-Bolt Pattern** (wheels, covers):
```
        1       3
        
        4       2
```
Criss-cross pattern.

**5-Bolt Pattern** (wheels):
```
            1
        5       2
        
        4       3
```
Star pattern.

### Angle Torque (TTY Bolts)

**Procedure**:
1. Torque to specified value (e.g., 30 ft-lbs)
2. Mark bolt head and surface
3. Turn bolt additional degrees as specified
4. Common angles: 45°, 60°, 90°, 180°

**Notes**:
- TTY bolts generally cannot be reused
- Angle torque stretches bolt to yield point
- Provides more accurate clamping force

### Torque-to-Yield Bolt Identification

- Usually have different head marking
- Often have specific service note
- Manufacturer specifies no reuse
- Common on head bolts, main bolts, rod bolts

## Common Torque Tools

### Torque Wrenches

| Type | Application |
|------|-------------|
| Click-type | Most applications |
| Beam-type | Verification, less accurate |
| Electronic | Precise applications, data logging |

### Calibration

- Calibrate annually or per manufacturer
- Check against known weight/arm length
- Don't drop or misuse torque wrench
