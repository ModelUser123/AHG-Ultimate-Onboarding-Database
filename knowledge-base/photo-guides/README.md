## Photo Documentation Standards

### When to Take Photos

**Always Document**:
- Pre-existing damage
- Component condition before repair
- Wear that justifies replacement
- Unusual findings
- After repair completion
- Customer complaints
- Warranty-related issues

**For Customer Communication**:
- Brake wear (with measurement)
- Tire wear patterns
- Fluid leaks
- Damaged components
- Failed parts

### Photo Quality Guidelines

**Technical Requirements**:
- Clear focus on subject
- Adequate lighting
- Clean lens
- Include reference (ruler, coin for scale)
- Multiple angles when needed

**Composition**:
- Fill frame with subject
- Avoid cluttered backgrounds
- Use flash when needed
- Take backup shots

### Documentation Process

1. **Before Work**:
   - Overall vehicle condition
   - Problem area close-up
   - Comparison to specification

2. **During Work**:
   - Component removal
   - Hidden damage found
   - Critical steps

3. **After Work**:
   - Completed repair
   - New components installed
   - Proper assembly verification

## Common Visual References

### Brake Pad Wear

**Measurement Guide**:

| Remaining Material | Status |
|-------------------|--------|
| 8-12 mm | New condition |
| 6-8 mm | Good |
| 4-6 mm | Fair, monitor |
| 2-4 mm | Replace soon |
| <2 mm | Replace immediately |
| Metal visible | Replace, check rotor |

**Visual Indicators**:
```
NEW PAD:        █████████████ (12mm)
50% WORN:       ███████       (6mm)
WORN OUT:       ██            (2mm)
METAL-METAL:    █ [DANGER]    (0mm)
```

### Rotor Condition

**Surface Conditions**:

| Condition | Description | Action |
|-----------|-------------|--------|
| Normal wear | Light scoring, uniform | Measure thickness |
| Deep grooves | Visible deep lines | Machine or replace |
| Hot spots | Blue/brown discoloration | Replace |
| Cracks | Visible cracks in surface | Replace immediately |
| Lip on edge | Raised edge at outer diameter | Indicates wear depth |

### Tire Wear Patterns

**Wear Indicator Visual Guide**:

```
CENTER WEAR:         EDGE WEAR (BOTH):    ONE SIDE WEAR:
  ___________          ___________          ___________
 |  [WORN]   |        |[W]    [W]|        |[WORN]     |
 |___________]        |___________|        |___________|
 
 Overinflation        Underinflation       Camber issue


FEATHER WEAR:        CUPPING/SCALLOPING:   FLAT SPOTS:
  ___________          ___________          ___________
 |//////////|        |~  ~  ~  ~ |        |   [F]     |
 |___________|        |___________|        |___________|
 
 Toe issue           Shock/strut wear      Balance/lockup
```

### Tire Tread Depth

| Measurement | Status |
|-------------|--------|
| 10/32" | New tire |
| 6/32" | 50% worn |
| 4/32" | Replace soon |
| 2/32" | Legal minimum |
| Below 2/32" | Unsafe, reject |

## Before/After Documentation

### Brake Job Documentation

**Before Photos Needed**:
1. Overall brake assembly
2. Pad thickness with measurement tool
3. Rotor condition (surface)
4. Caliper condition
5. Brake line/hose condition

**After Photos Needed**:
1. New pads installed
2. Rotor surface (machined or new)
3. Complete assembly
4. Hardware properly installed

### Engine Repair Documentation

**Before**:
- Engine bay overview
- Failed component close-up
- Evidence of failure (leak, break, etc.)
- Measurement if applicable

**After**:
- New component installed
- Proper routing/positioning
- Torque verification (if visible marks used)
- Clean installation

## Wear Indicators

### Belt Condition

**Visual Guide**:

| Condition | Appearance | Action |
|-----------|------------|--------|
| New | Smooth ribs, no cracks | None |
| Good | Minor surface wear | Monitor |
| Worn | Cracks in ribs | Replace soon |
| Cracked | Multiple cracks, chunking | Replace now |
| Glazed | Shiny, slick surface | Replace |

### Hose Condition

| Condition | Visual Signs | Action |
|-----------|--------------|--------|
| Good | Firm, no cracks | None |
| Soft | Spongy feel | Replace soon |
| Cracked | Visible surface cracks | Replace |
| Swollen | Bulging areas | Replace immediately |
| Leaking | Wet spots, residue | Replace immediately |

### Ball Joint/Tie Rod Wear

**Inspection Visual Cues**:
- Movement when loaded
- Torn or missing boot
- Grease leakage
- Corrosion at joint

**Measurement**:
| Component | Maximum Play |
|-----------|--------------|
| Ball joint (radial) | 0.050" |
| Ball joint (axial) | Spec varies |
| Tie rod end | Zero play |

### CV Boot Condition

| Condition | Description | Action |
|-----------|-------------|--------|
| Good | Intact, pliable | None |
| Cracked | Small surface cracks | Replace boot |
| Torn | Visible split/hole | Replace axle or boot |
| Grease visible | Grease on suspension | Replace axle |

## Fluid Identification

### Fluid Color Chart

| Color | Texture | Location | Likely Fluid |
|-------|---------|----------|--------------|
| Green | Watery, sweet smell | Radiator area | Coolant (IAT) |
| Orange | Watery, sweet smell | Radiator area | Coolant (OAT) |
| Pink | Watery, sweet smell | Radiator area | Coolant (HOAT) |
| Red/pink | Oily, slippery | Trans area | ATF |
| Dark red | Oily, burnt smell | Trans area | Old ATF |
| Light brown | Oily | Engine area | Fresh oil |
| Dark brown | Thick, dirty | Engine area | Used oil |
| Clear | Watery | Under AC | Condensation |
| Amber/light | Oily | Brake area | Brake fluid |
| Dark, thick | Heavy oil | Diff/axle | Gear oil |

### Coolant Condition

| Appearance | Condition | Action |
|------------|-----------|--------|
| Clear, bright | Good | None |
| Slightly dark | Aging | Monitor |
| Rusty/brown | Contaminated | Flush system |
| Milky | Oil contamination | Head gasket check |
| Oily film | Oil leak into system | Investigate |

### Oil Condition

| Appearance | Condition | Action |
|------------|-----------|--------|
| Amber, clear | Fresh | None |
| Dark brown | Normal use | Change per interval |
| Black, thick | Overdue | Change immediately |
| Milky | Coolant mixing | Head gasket check |
| Metallic particles | Wear | Investigate |

## Building Your Photo Library

### Organizing Photos

**Folder Structure**:
```
Photos/
├── By_Make/
│   ├── Ford/
│   ├── GM/
│   ├── Toyota/
│   └── ...
├── By_System/
│   ├── Brakes/
│   ├── Suspension/
│   ├── Engine/
│   └── ...
├── By_Procedure/
│   ├── Timing_Belt/
│   ├── Head_Gasket/
│   └── ...
└── Reference/
    ├── Wear_Indicators/
    ├── Specifications/
    └── Diagrams/
```

### Photo Naming Convention

**Recommended Format**:
`[Year]_[Make]_[Model]_[System]_[Description]_[Date]`

**Examples**:
- `2018_Toyota_Camry_Brakes_WornPads_20240115`
- `2020_Ford_F150_Engine_OilLeak_20240115`

### Building Reference Library

**Document These Regularly**:
1. Common procedures
2. Specification locations
3. Bolt patterns
4. Torque sequences
5. Unusual configurations
6. Hard-to-find components
7. Factory vs. aftermarket differences

### Using Photos for Training

**Training Photo Sets Should Include**:
- Good vs. bad comparisons
- Measurement technique examples
- Step-by-step procedures
- Safety considerations
- Common mistakes to avoid

- DSLR or mirrorless camera

## Digital Vehicle Inspection (DVI)

### DVI Photo Requirements

**Per Inspection Point**:
- Clear image of condition
- Measurement visible if applicable
- Context for location
- Green/Yellow/Red indicator

**Photo Quality for DVI**:
- Adequate lighting
- Sharp focus
- Professional presentation
- Customer-friendly perspective

### Customer-Facing Photos

**Best Practices**:
- Clean the area first if dirty
- Remove distractions from frame
- Add text annotations if helpful
- Compare to specification
- Show measurement device
